# 백엔드 개발 결과 보고서

검증일: 2026-11-24 (한국 시간)

## 작업 기준

현재 작업 브랜치 `JJW`에서 구현했다. 원격 `origin/dev` 존재를 확인했고 브랜치 전환이나 병합은 하지 않았다.
공통 의존성, 스키마, API 기본 코드, 모델 래퍼, CI가 이미 있어 중복 생성하지 않고 확장했다.
외부 담당자 코드와의 통합은 수행하지 않았다.

## 완료 기능

| 항목 | 결과 |
|---|---|
| FastAPI | 앱 생성, lifespan 모델 로딩, Swagger/OpenAPI 제공 |
| GET /health | 서버 상태·버전·가격/분류 모델 준비 상태 반환 |
| POST /predict/price | 가격 없는 입력 검증 → 공통 파생변수 → 모델 호출 → 원 단위 가격 반환 |
| POST /predict/anomaly | 실제 거래가격 필수, 단위면적 가격 생성, 이상 확률·임계값·의심 여부·판정 한계 반환 |
| POST /scenario/interest-rate | 동일 조건의 금리만 변경, 가격 차이·변화율·외삽 경고·비인과성 안내 반환 |
| 모델 미준비 | 없는 파일·손상 파일·미학습 모델에 대해 503, 임의 판정 없음 |
| 오류 | 422/503/500 및 404/405의 detail.code/message 형식, 입력 오류의 필드 위치 제공 |
| 출력 검증 | 예측 배열 크기, NaN/Infinity, 분류 확률과 임계값 범위 검증 |
| CORS | localhost 3000/5173 기본 허용, 환경변수로 변경, 500 응답에도 허용 출처 헤더 제공 |
| 로그 | 요청 ID, 경로, 상태 코드, 처리시간 및 서버/모델 오류 traceback 기록 |
| 문서 | API 계약 갱신, 실행 가이드, ML·프론트엔드 인수인계 계약 |

가격 예측 요청에는 `price_krw`를 허용하지 않는다. 분류 응답의 참고가격 계산에도 가격을 제외한
특성 프레임을 사용한다. 분류 모델만 있는 경우 참고가격과 괴리율은 null로 반환한다.
시나리오 기준 예측가격이 0일 때 변화율은 null이며, 음수일 때는 명세대로 계산하고 경고한다.

## 이번 보완 내용

기존 네 API와 공통 계약을 재사용했다. 오류 통일, CORS, 요청 추적, 손상 모델 로딩 실패 처리,
예측값 검증, 음수·0 기준가격 계산 처리, 회귀 입력 격리와 추가 테스트를 구현했다.
금리를 사용하지 않는 모델만 SCENARIO_NOT_SUPPORTED로 분류하고, 모델 실행 실패는 500으로 구분한다.
Windows asyncio의 내부 socketpair 생성이 기존 테스트 네트워크 차단에 걸리는 문제도 수정했다.

## 검증 결과

환경: Windows, Python 3.13.11, 프로젝트 `.venv`.

| 검증 | 결과 |
|---|---|
| pytest 전체 | 87 passed |
| ruff check . | 통과 |
| ruff format --check . | 42개 파일 통과 |
| python -m apartment_ml.pipeline | 기존 합성 데이터 smoke 실행 성공 |
| 실제 Uvicorn 시작 | 127.0.0.1:8765 임시 실행 성공, 확인 후 종료 |
| 실제 HTTP /health | 200, status=ok, price=false, anomaly=false |
| 실제 HTTP /openapi.json | 네 API 등록 확인 |

API 성공 경로는 테스트 전용 가짜 모델로 검증했다. 기존 모델 테스트는 합성 데이터를 사용한다.
가격·분류 API, 입력 오류, 모델 미준비, 손상 파일, 예측 실패, CORS,
시나리오 계산·금리 외 조건 고정·0/음수 기준가격·비정상 출력을 검증했다.
설치된 Starlette에서 httpx TestClient 사용 중단 예정 경고 1개가 발생하며 테스트 실패는 없다.

## 미구현 또는 미검증

| 항목 | 이유 / 후속 작업 |
|---|---|
| 실제 학습 모델의 배포·예측 검증 | 모델 파일 전달 후 설정 경로에 배치하고 실제 입력·출력 확인 필요 |
| 실제 이상거래 판정 품질 | 정답 레이블과 학습 모델 필요. 준비 전에는 503 반환 |
| 프론트엔드 화면 연동 | 프론트엔드 미제공. 계약/CORS/TestClient까지만 준비 |
| 데이터→실제 모델→API→화면 전체 통합 | 사용자 요청 범위에서 제외 |
| 원격 GitHub Actions 실행 결과 | 기존 CI 구성을 재사용하고 동일 명령을 로컬 실행. push/PR 미수행 |
| 운영 배포 | 요청 범위에서 제외. 로컬 서버 실행만 확인 |

사용자에게 보여줄 실제 예측 성능이나 모델 기반의 실거래 판정 결과는 아직 검증하지 않았다.
API 내부 연결 검증 결과를 실제 모델·프론트엔드 통합 완료로 해석하면 안 된다.

실행 방법은 [BACKEND_GUIDE](BACKEND_GUIDE.md), 요청·응답 계약은 [API_CONTRACT](API_CONTRACT.md)를 참조한다.
