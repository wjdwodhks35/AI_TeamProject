## 8. 레이블 검증

레이블을 우리가 정했기 때문에, 우리 기준으로 평가하면 순환입니다. **밖에서 주어진 사실**과 겹치는지
확인했습니다.

| | 이상거래 | 저가거래 | 정상 거래 | 배수 |
|---|---|---|---|---|
| 직거래 비율 | 16.1% | **40.4%** | 1.9% | 8.6배 / **21.5배** |
| 관외 중개 비율 | 4.4% | - | 2.2% | 2.0배 |
| 해제율 | 6.06% | - | 4.92% | 1.2배 |

**시세에서 20% 이상 싼 거래의 40.4%가 중개사를 거치지 않은 직거래였습니다.** 전체 평균은 1.9%입니다.
서로 다른 방법으로 찾았는데 같은 거래를 가리킵니다.

직거래 여부는 레이블을 만들 때 쓰지 않았습니다. 다만 입력 변수로도 쓰면 검증으로서의 독립성이
사라지므로, 모델을 만들 때 **넣은 경우와 뺀 경우를 비교**해야 합니다.

### 해제율로 검증할 때의 제약

해제는 계약 후 한참 뒤에 일어납니다.

| 계약 후 경과 | 최종 해제 중 드러난 비율 |
|---|---|
| 1개월 | 46.6% |
| 3개월 | 83.9% |
| **6개월** | **96.5%** |
| 12개월 | 99.1% |

최장 1,845일(약 5년)이었고, 1년 넘는 건은 127건(0.88%)입니다. 장기 해제는 직거래에 몰려 있습니다
(최장 5건 중 4건).

따라서 해제율로 검증할 때는 **최근 2~3개월을 제외**해야 합니다. 우리가 뽑는 거래에 직거래가 많이
섞여 있고 직거래는 해제가 늦게 드러나므로, 최근 구간에서는 우리 쪽 해제율만 덜 차서 결과가 나쁘게
나옵니다.

## 10. 다른 담당자에게 전달

**머신러닝 담당자**

- 입력 변수: `schemas.REGRESSION_FEATURES`, `schemas.CLASSIFICATION_FEATURES`
- 금리는 **수준이 아니라 변화량**(`base_rate_change_12m`)을 쓸 것
- 레이블은 `peer_tier`가 1 또는 2인 174,917건만 사용. 정의는 합의 필요
- **입력 금지:** `peer_median_price_krw`, `price_ratio`, `peer_tier` — 레이블을 역산할 수 있음
- 기간 한정: `is_direct_deal`을 쓰면 2022년 이후, 해제 검증은 2026-06까지
- 기준선: 지역·평형별 중앙값을 먼저 재고 모델이 그것을 이기는지 볼 것

**백엔드 담당자**

- 입력 형식: 자치구명(한글), 계약일(`YYYY-MM-DD`), 면적(㎡), 층(정수, 음수 가능)
- 금리 시나리오는 사용자가 **수준**(예: 3.0%)을 넣고, 내부에서 **현재 대비 변화량**으로 바꿔 모델에 전달
- 슬라이더 범위는 현재 ±1.5%p로 제한. 학습 범위를 벗어나면 트리 모델이 끝값을 반복함
